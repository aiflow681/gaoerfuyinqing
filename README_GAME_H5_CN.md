# 阳光高尔夫（Cocos Creator 3.8.8，网页端）

## 已实现内容

- 纯前端网页迷你高尔夫玩法
- 8 个难度递进关卡
- 障碍与机关：固定墙、动态移动墙、沙坑、水域、风区、加速带
- 成绩追求循环：标准杆、星级评分、最大杆数、最佳成绩存档
- 本地进度保存（已解锁关卡 + 最佳成绩）
- 鼠标与触屏拖拽击球

## 在 Cocos Creator 中的一次性设置（零基础也能做）

1. 用 `Cocos Creator 3.8.8` 打开本工程。
2. 新建一个场景（例如 `Main.scene`）。
3. 如果场景里没有 `Canvas`，先创建一个 `Canvas` 节点。
4. 选中 `Canvas`。
5. 添加脚本组件：`SunGolfGame`（路径：`assets/scripts/SunGolfGame.ts`）。
6. 保存场景，并设置为启动场景。
7. 点击预览，即可在浏览器中运行。

## 构建网页版本

1. 打开 `项目 -> 构建发布`。
2. 选择 `Web Mobile`（或 `Web Desktop`）。
3. 点击构建，再点击运行。

## 基本玩法

- 按住小球
- 向反方向拖拽蓄力
- 松手击球
- 在最大杆数内把球打进洞
- 重玩关卡刷新最佳成绩与星级
