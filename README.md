【游戏名称】 阳光高尔夫

【游戏介绍】 这是一款基于 Cocos 引擎开发的高尔夫闯关小游戏（Cocos Creator 3.8.8）。游戏中，你需要控制小球击打方向与力度，让球顺利进入球洞，在不同地形与障碍条件下完成关卡挑战，尽量用更少杆数过关。

【玩法说明】 游戏中玩家需要根据场景中的球洞位置与障碍布局，调整击球角度和力度，将高尔夫球打入目标区域并完成关卡。

道具： 本版本以基础高尔夫击球玩法为主，常见关卡元素包含球洞、障碍物、边界、反弹路径与力度控制。

1. 起始球位： 每关开始时小球会出现在指定位置，作为击球起点。
2. 目标球洞： 将小球成功送入球洞即可完成当前关卡目标。
3. 障碍区域： 场景中可能存在墙体、边界或地形阻挡，需要规划路径绕过。
4. 力度控制： 击球力度会影响小球移动距离，力度过大或过小都可能影响过关。
5. 角度与反弹： 合理利用击球角度与边界反弹，可以更高效地命中目标。

操作： 你可以通过鼠标点击/拖动（PC 端）或手指触控拖动（移动端）进行瞄准与击球操作。游戏为 web-mobile 构建版本，支持浏览器内交互体验。

目标： 在规则允许的条件下将小球打入球洞，尽量减少击球次数，提高关卡完成效率与得分表现。

Tips： 先观察球洞与障碍位置再出杆；优先尝试稳定路线；遇到复杂关卡时可利用边界反弹修正路径。

【技术介绍】 使用基于 Cocos 引擎的 Cocos Creator 3.8.8 开发的 H5 游戏，主要语言为 JavaScript，构建平台为 web-mobile。项目入口为 index.html，运行时通过 SystemJS 加载 cocos-js/cc.js 与资源配置，支持 PC 和移动端浏览器。
